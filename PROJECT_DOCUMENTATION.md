## Обзор проекта

**Pass Vault v2.0** - это встраиваемая система хранения паролей на базе микроконтроллера STM32F411CEU6 с энергонезависимой памятью EEPROM Microchip 25AA064/25LC064 (25064JVS1Q). Проект разработан на языке программирования Ada с использованием GNAT Compiler для ARM Cortex-M4.

### Назначение
- Хранение учётных данных (ключ-значение)
- Интерактивное меню через последовательный порт
- Поддержка до 10 записей
- Энергонезависимое хранение данных

## Аппаратная платформа

### Микроконтроллер: STM32F411CEU6

| Параметр | Значение |
|----------|----------|
| Ядро | ARM® Cortex®-M4 32-bit RISC |
| Частота | до 100 МГц |
| Flash-память | 512 Кбайт |
| SRAM | 128 Кбайт |
| Корпус | UFQFPN48 (7×7 мм) |
| Напряжение питания | 1.7 В - 3.6 В |
| Рабочая температура | -40°C ... +85°C |

### Память EEPROM: Microchip 25AA064/25LC064 (25064JVS1Q)

| Параметр | Значение |
|----------|----------|
| Ёмкость | 64 Кбит (8 Кбайт) |
| Интерфейс | SPI (Serial Peripheral Interface) |
| Максимальная частота SPI | 10 МГц (25LC064), 5 МГц (25AA064) |
| Напряжение питания | 2.5В - 5.5В (25LC064), 1.8В - 5.5В (25AA064) |
| Корпус | TSSOP-8 / SOIC-8 |
| Организация | 8192 × 8 бит |
| Страница записи | 32 байта |
| Циклы записи/стирания | > 1 млн циклов |

### Подключение периферии

#### 1. USART1 (Консольный интерфейс)

| STM32F411CEU6 | Функция | Описание |
|---------------|---------|----------|
| PA9 | TX | Передача данных (3.3V TTL) |
| PA10 | RX | Приём данных (3.3V TTL) |

**Настройки USART1:**
- Baud Rate: 115200 бод
- Data Bits: 8
- Stop Bits: 1
- Parity: None
- Overampling: 8x (OVER8 = True)

#### 2. SPI1 (EEPROM 25AA064/25LC064)

| STM32F411CEU6 | EEPROM 25xx64 | Описание |
|---------------|---------------|----------|
| PA5 (SPI1_SCK) | Pin 6 (SCK) | Тактовый сигнал SPI |
| PA6 (SPI1_MISO) | Pin 5 (SO) | Master In Slave Out |
| PA7 (SPI1_MOSI) | Pin 2 (SI) | Master Out Slave In |
| PA4 (SPI1_NSS) | Pin 1 (CS) | Chip Select (активный низкий) |
| 3.3V | Pin 8 (VCC) | Питание |
| GND | Pin 4 (GND) | Земля |
| — | Pin 3 (WP) | Write Protect (подтянуть к GND) |
| — | Pin 7 (HOLD) | Hold (подтянуть к VCC) |

```
                    ┌─────────────────┐
         CS (PA4)──►│ 1 CS        VCC │──► 3.3V
    MOSI (PA7)──►│ 2 SI       HOLD │──► 3.3V (Pull-up)
             GND──►│ 3 WP        SO │──► MISO (PA6)
             GND──►│ 4 GND       SCK │──► SCK (PA5)
                    └─────────────────┘
                        EEPROM 25xx64
                        (вид сверху)
```

#### 3. LED Индикатор (PC13)

| STM32F411CEU6 | Компонент | Описание |
|---------------|-----------|----------|
| PC13 | LED (катод) | Встроенный светодиод на плате NUCLEO |

**Подключение:**
- Анод LED → 3.3V через резистор 220Ω
- Катод LED → PC13

**Логика работы:**
- `PC13 = LOW` → LED включён
- `PC13 = HIGH` → LED выключен

### Инициализация системы

```ada
-- 1. Инициализация тактирования (HSI 16 MHz)
RCC_Periph.CR.HSION := True;
loop exit when RCC_Periph.CR.HSIRDY; end loop;

-- 2. Инициализация GPIO (PA9 TX, PA10 RX, PC13 LED)
RCC_Periph.AHB1ENR.GPIOAEN  := True;
RCC_Periph.AHB1ENR.GPIOCEN  := True;
RCC_Periph.APB2ENR.USART1EN := True;

-- 3. Настройка USART1 (115200 бод)
USART1_Periph.CR1.RE := True;
USART1_Periph.CR1.TE := True;
USART1_Periph.BRR.DIV_Mantissa := 17;
USART1_Periph.BRR.DIV_Fraction := 3;
USART1_Periph.CR1.UE := True;

-- 4. Настройка LED (PC13)
GPIOC_Periph.MODER.Arr(13) := 2#01#;  -- Output mode
```

## Функциональные возможности

### Команды меню

| Команда | Описание | Параметры |
|---------|----------|-----------|
| `1` | List entries | Показать все записи |
| `2` | Add entry | Ввод ключа и значения |
| `3` | Delete entry | Номер записи для удаления |
| `4` | Clear all | Подтверждение "YES" |

### Формат ввода

```
=== Pass Vault v2 ===
1. List entries
2. Add entry
3. Delete entry
4. Clear all
> _
```

**Пример добавления записи:**
```
> 2
Key: my_login
Val: secret_password123
 [OK]
```

**Пример просмотра:**
```
> 1

--- Database ---
1. my_login | secret_password123
2. email | user@example.com
```

## Технические характеристики

### Производительность

| Параметр | Значение |
|----------|----------|
| Тактовая частота CPU | 16 МГц (HSI) |
| Скорость USART | 115200 бод |
| Максимальная скорость SPI | до 10 МГц |
| Время отклика меню | < 1 мс |
| Запись в EEPROM | ~5 мс на байт |

### Потребление памяти

| Ресурс | Использование |
|--------|---------------|
| Flash (код) | ~8-12 Кбайт |
| SRAM (данные) | ~1-2 Кбайт |
| EEPROM (данные) | до 640 байт (10 записей) |

### Ограничения

- Максимум 10 записей в базе данных
- Максимальная длина ключа: 32 символа
- Максимальная длина значения: 32 символа
- Данные хранятся в RAM (требуется доработка для записи в EEPROM)

## Протоколы связи

### USART Frame Format

```
Start Bit │ D0 D1 D2 D3 D4 D5 D6 D7 │ Stop Bit
    0     │    LSB ........... MSB   │     1
    
Total: 10 bits per character
Speed: 115200 bps ≈ 11.5 KB/s
```

### SPI Frame Format (для EEPROM)

```
Write Enable (WREN):
  CS ──┐
       │╲
       │ ╲ Command: 0x06
       │  ╲___________
       │              │
       └──────────────┘

Read Sequence:
  CS ──┐
       │╲
       │ ╲ Command: 0x03 │ Addr High │ Addr Low │ Data...
       │  ╲______________│___________│__________│_______
       │                 │          │          │
       └─────────────────┴──────────┴──────────┘

Write Sequence:
  CS ──┐
       │╲
       │ ╲ Command: 0x02 │ Addr High │ Addr Low │ Data...
       │  ╲______________│___________│__________│_______
       │                 │          │          │
       └─────────────────┴──────────┴──────────┘
```

### EEPROM Commands

| Command | Code | Описание |
|---------|------|----------|
| WREN | 0x06 | Set Write Enable Latch |
| WRDI | 0x04 | Reset Write Enable Latch |
| READ | 0x03 | Read Data from Memory |
| WRITE | 0x02 | Write Data to Memory |
| RDSR | 0x05 | Read Status Register |
| WRSR | 0x01 | Write Status Register |
